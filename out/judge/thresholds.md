# 中文网文正文「可读性」阈值建议

> 用途：这份表里的数字会被写进生成 prompt 的硬约束，也会被用来做自动门禁。
> 所有数字都不是拍脑袋来的，来源只有三处：① 实测本仓库 A/B/C/D 四批正文；
> ② 仓库里唯一的人类小说片段 `samples/human_01.txt`（294 字，`ai_flavor.py` 判 **5.9 分「人味充足」**）；
> ③ 同一场景的 AI 版本 `samples/ai_01.txt`（`ai_flavor.py` 判 **51.7 分「明显 AI 味」**）。
> 工具：`python src/prose_judge.py <file_or_dir> [--json out/judge/x.json]`。

---

## 0. 先把话说清楚：哪些数字有依据，哪些是我拍的

| 类别 | 指标 | 依据 |
|---|---|---|
| **有依据**（人类样本守得很死，AI 样本/改良版都越线） | '的'字密度、长句占比、解释句占比、静物句占比、代称密度 | human_01 = 1.70 / 7.4% / 0% / 0% / 0 |
| **无依据**（人类样本自己就"超标"） | 碎句段/千字、≤6字句占比、碎动作链 | human_01 = 6.8 / 51.9% / 18.5%，比 A 批还极端 |
| **不可靠**（启发式明显失真） | 每300字新增专名数、对话"给新信息"轮占比 | 见第 3 节 |

**关键教训**：`samples/human_01.txt` 是一段好文字（"他把车停在村口，没熄火。／引擎抖，方向盘也跟着抖。"），
但它 **51.9% 的句子 ≤6 字、6.8 段/千字连续短句、18.5% 碎动作链**。
所以"碎"本身不是病，是风格。**任何把"短句多"当红线的门禁都会误杀好文**——
`ai_flavor.py` 给这段 5.9 分，就是因为它没有把"碎"当病。
这就是本工具给出**两套口径**的原因：主口径按读者体验罚碎句，第二口径把碎句基准放到人类样本水平。
两套口径排名一致的部分才是可信结论。

## 1. 硬约束（这 8 个数写进 prompt，超了就该重写）

单位与口径见 `src/prose_judge.py` 的 `LIVE_THRESHOLDS`。**"合格线"= 不扣分，"红线"= 扣满分。**

| # | 指标 | 合格线 | 警戒 | 红线 | 实测对照（人类 / A / B / C） | 依据 |
|---|---|---|---|---|---|---|
| 1 | **'的'字密度**（个/百字） | **≤2.0** | 2.0~3.2 | **≥4.5** | 1.70 / 2.10 / 2.49 / 3.46 | 人类 1.70；AI 样本 5.16（3 倍）；`ai_flavor` human_ref 4.0 / ai_ref 8.0 太松，实测 3.5 以上就已明显"定语糊墙" |
| 2 | **'的…的…的'三连**（处/千字） | **0** | 0~0.5 | **≥4.0** | 0 / 0 / 0 / 0 | 四批全是 0，说明正常中文不该出现；`docs/02-ai-flaws.md` 把它列为 A2 定语堆叠主症 |
| 3 | **单句 ≥3 个'的'的句子占比** | **≤2%** | 2~5% | **≥8%** | 0% / 0.6% / 3.0% / 1.0% | 人类样本 0% |
| 4 | **长句占比（单句 ≥35 字）** | **≤8%** | 8~13% | **≥18%** | 7.4% / 2.3% / 18.8% / 8.3% | 人类 7.4% 是上限参考；B 批 18.8% 是"一句话塞三个设定"的直接证据 |
| 5 | **解释句占比**（含 因为/所以/要是/否则/意味着/等于/说白了 的叙事句） | **≤1.5%** | 1.5~4% | **≥8%** | 0% / 0.09% / 3.6% / 2.1% | 人类 0%、AI 样本 0%；B 批 3.6% 全是"如果…就等于…"的说明文腔 |
| 6 | **纯静物/环境句占比**（无人物、无人的动作、无因果/条件/时间推进/规则后果、且含器物或环境名词） | **≤2%** | 2~6% | **≥12%** | 0% / 4.8% / 3.0% / 6.2% | 人类 0%。这是读者"描述过重"投诉最贴近的可计算形态 |
| 7 | **代称密度**（少年/少女/老人/老者/汉子/姑娘/丫头/那人…，次/千字） | **≤0.5** | 0.5~3 | **≥5.0** | 0 / 1.11 / **9.31** / 0 | 人类 0。B 批 9.31 是三批最严重的单项 |
| 8 | **连续 ≥3 句同开头**（段/千字） | **≤0.2** | 0.2~1 | **≥2.0** | 0 / 0.09 / 0 / 0 | 人类 0；D 批 0.98（"他…他…他…"）是反面样本 |

**本批实测总分**：A = 82.5（第二口径 94.5）／B = 75.3（75.8）／C = 88.1（88.1）／D⚠ = 65.4（prompt 固件，不可用）。

### 附：动作复读（≥3 次的重复短语，个/千字）
合格 **≤1.0**，红线 **≥6.0**。实测 0 / 0.34 / 0 / 0，D 批 0.98。
本仓库四批都不严重，但它是抓"机器复读"最灵的一项，建议保留在门禁里（成本低、几乎不误伤）。

### 附：逗号链（单句 ≥4 个逗号占比）
合格 **≤8%**，红线 **≥20%**。实测 人类 7.4% / A 3.0% / B 0.6% / C 0。
**注意**：人类样本 7.4%，所以"一句四个逗号"不算硬伤；真正的问题在"一句 35 字以上"（指标 4），
两者不要混用，否则会把正常的中文长句判死。

## 2. 只做诊断、**不要**写进 prompt 的指标

| 指标 | 实测（人类 / A / B / C） | 为什么不进 prompt |
|---|---|---|
| 连续 ≥3 句 ≤6 字（段/千字） | **6.8** / 3.42 / 0 / 0 | 人类样本比 A 批还高。写进 prompt 会逼模型把"砸节奏的短句"删光，直接毁掉网文节奏 |
| ≤6 字句占比 | **51.9%** / 35.5% / 21.8% / 15.5% | 同上。人类样本 51.9%，按这个数字去"优化"，好文会被判死 |
| 碎动作链句占比（≥3 分句且均 ≤8 字） | **18.5%** / 19.3% / 0 / 0 | 人类样本 18.5%。它区分不了"具体生动的连动"（"二叔把化肥往地上一撂，走过来，手在裤腿上蹭了两下"）和"无关小动作堆叠" |

**这三项怎么用**：只看"有没有和别的病一起出现"。
判据（我建议写进门禁代码，而不是 prompt）：

```
碎句超标 且 (静物句 > 6% 或 对话给新信息 < 40%)  →  判"电报体"，要求重写
碎句超标 且 静物句 ≤ 2% 且 对话给新信息 ≥ 50%      →  判"风格碎"，放过
```

A 批正好落在第二种（碎句 3.42 超标，但静物 4.8%、对话新信息 44%）——
**所以我不认为 A 批的"碎"是病**，这与读者投诉并不矛盾：读者抱怨的是"读起来费劲"，
而费劲在 A 批的可计算证据是 **静物句 4.8%（人类 0%）+ 代称 1.11（人类 0）+ 对话 56% 不给新信息**，
不是"句子太短"。

## 3. 不可靠指标（明确标注，不要进 prompt，也不要当门禁）

| 指标 | 为什么不可靠 | 本工具怎么处理 |
|---|---|---|
| **每 300 字新增专名数** | 靠"姓氏表 + 1~2 字"和"器物/地名后缀表"切，复姓、法号、绰号会漏；"石阶上""面铜镜"这类会被误切。实测 B 批切出 `屋门`、`印记`，D 批切出 `东西早` | 打分里保留（权重 6，双边界），但报告里标 `[不可靠]`，并**把切出来的专名清单全列出来供人工审计** |
| **对话"给新信息"轮占比** | 启发式数不出"手没抖。"这种短促但有信息量的台词，会误记成空转。实测 A 批 51.8% 被判"空转"，但里面很多是有效对白 | 标 `[不可靠]`，只在报告里当趋势看；**不要**用它单独判对白质量 |
| 句首二字去重率（`ai_flavor` M21 口径） | A 批 0.377 远低于 `ai_flavor` 的 human_ref 0.90，但 A 的"连续同头"只有 0.09/千字——说明这只是"开头词汇池窄"，不是硬伤 | 只做诊断输出，打分用"连续 ≥3 句同头" |
| 4-gram 重复率（`ai_flavor` M20） | A 批 5.4% 被判"致命"，但那主要来自"他没动。／他没动。"这类短句复读，是风格不是抄袭 | 交给 `ai_flavor.py` 管，本工具不重复计分 |

## 4. 和 `src/ai_flavor.py` 的 human_ref / ai_ref 对照

`ai_flavor.py` 是通用 AI 味检测器，它的参考值是给"通用中文"用的，直接搬到小说正文会松/紧错位：

| 指标 | ai_flavor human_ref → ai_ref | 本工具建议 | 差异原因 |
|---|---|---|---|
| '的'字密度 | 4.0 → 8.0（个/百字） | **≤2.0**（红线 4.5） | ai_flavor 的 4.0 太松：实测 3.46（C 批）读起来已经明显"定语糊墙"，而人类样本是 1.70 |
| 短句占比(≤8字) | 0.36 → 0.09（人写**更多**短句） | 不进 prompt | ai_flavor 认为短句多是"人味"，我同意；但它的阈值方向会让"优化模型"去增加长句，所以只能当诊断 |
| 长句占比(≥45字) | 0.09 → 0.02（人写**更多**长句） | 单句 **≥35 字 ≤8%** | 45 字太宽，实测 B 批 18.8% 的 35~60 字长句已经在伤可读性 |
| 句首多样性 | 0.88 → 0.68（≥0.90 才合格） | 连续同头 ≤0.2 段/千字 | 0.90 的绝对门槛会把 A 批（0.377）直接判死，但 A 并没有"连续同头"问题 |
| 段末升华率 | 0.06 → 0.42 | 不测 | 这是"上价值"问题，属于 `ai_flavor` 的领域，和"读起来累"关系不大 |

**两个工具的结论会打架，而且都对**：`ai_flavor` 给 A 批首章 27.2 分「明显 AI 味（单项致命）」、
给 B 批 13.1 分「人味充足」；本工具给 A 批 82.5、B 批 75.3。
原因：`ai_flavor` 罚的是 **4-gram 复读**（A 首章 5.4%，B 1.8%），
我罚的是 **读者负担**（B 的长句/代称/解释）。**两个都要看，不能互相替代。**

## 5. 字数

- **目标 3000~4000 汉字/章**（读者诉求原文）。建议门禁：`2800 ≤ 字数 ≤ 4200`，超出即重写末段/删场景。
- 实测 A 批 19 章：3221~5991 字，**13/19 在区间内，6 章超 4200**（最长 5991），0 章低于 3000。
  → 读者的"字数偏多"投诉**部分成立**：中位数没问题，长尾（尤其 5991 字那章）该砍。
- ⚠ 冲突提醒：`docs/02-ai-flaws.md` 第 793 行的旧门禁写的是 `字数 ∈ [4500, 5500]`。
  那是"5000 字/章"时代的标准，**与读者现在的 3000~4000 要求冲突**，以本文档为准。
- 字数不该进"可读性分"（写得少不等于好读），但必须进 prompt 和门禁。

## 6. 可直接粘进生成 prompt 的补丁（建议原文照抄）

```
【可读性硬约束·超一条即重写该段】
1. '的'字密度 ≤2.0 个/百字；禁止出现"…的…的…的"三连；单句用'的'不超过 2 个。
2. 单句 ≤35 字；≥35 字的长句每千字不超过 2 句。一句话只推进一件事。
3. 禁止解释句：不要用"因为/所以/要是/否则/意味着/等于/说白了"给读者总结因果。
   因果交给动作和对话，让读者自己推。每千字此类句式 ≤2 句。
4. 禁止纯静物句：每句话里必须有人在做事、或在说话、或时间在推进。
   环境描写必须挂在人物的动作上（"他把油灯往中间推了推"而不是"油灯搁在桌案正中"）。
   静物句占比 ≤2%。
5. 禁止用代称代替名字：少年/少女/老人/老者/汉子/姑娘/丫头/那人/此人 每千字 ≤0.5 次。
   同一个角色第一次出场用全名，之后用名字或"他/她"，不要换着叫。
6. 同一动作短语（"他退了一步""他攥了攥拳"）全文不得出现 3 次以上。
7. 连续 3 句不要用同一个词开头（尤其是"他/她/名字"）。
8. 每 300 字新增专名 ≤1.5 个；一次只交代一个新设定，不要在一段里连开三个新名词。
9. 正文字数 3000~4000 汉字。超出就删场景，不要靠加描写凑。
```

**配套门禁（代码用，不进 prompt）**：

```
通过 = 字数∈[2800,4200]
     ∧ 的字/百字 ≤3.2 ∧ 三连 = 0 ∧ 单句≥3个的 ≤5%
     ∧ 长句(≥35字) ≤13% ∧ 解释句 ≤4% ∧ 静物句 ≤6%
     ∧ 代称/千字 ≤3.0 ∧ 同头段/千字 ≤1.0 ∧ 动作复读短语 ≤3
     ∧ 若(碎句段 >2.0 且 (静物句 >6% 或 对话新信息 <40%)) → 判电报体，重写
```

## 7. 采样与误判风险（写进 CI 注释）

1. **<2000 字的样本，所有比例类指标都不可信**（C 批只有 1560 字，专名密度天然偏高）。门禁只对完整章生效。
2. **`静物句` 依赖人物名词表**：如果一章里人名没被启发式认出来，静物句会虚高。改人名启发式后要重跑基线。
3. **`解释句` 只测"叙事句"**，对话里的"因为…所以…"不算——因为角色说话本来就该讲道理。
4. **`碎句`/`碎动作链` 两项会误伤文学性强的短句风格**（见第 2 节），永远不要单独用它们判死。
5. **两套口径的分数只在同一批内可比**，不要拿 A 批（19 章合并 7.3 万字）和 C 批（1560 字单段）的分差当结论强度。
