## 0. 为什么人物是"半硬"

世界观是**硬编码**的（第 0 步），人物是**半硬**的：

| 维度 | 硬/软 | 为什么 |
|---|---|---|
| 境界轨迹 | **硬** | 否则第 3000 章沈鹤年突然从元婴变化神，读者立刻发现 |
| 声纹（语气/口头禅/绝不说） | **硬** | 5000 章里所有角色一个味，读者分不清谁在说话 |
| 不可变事实（疤痕/残缺） | **硬** | 写进正典，全书不能改 |
| 灵根 / 出身 / 关系 | **半硬** | 结构化但允许剧情推进 |
| 人物弧光 | **软** | 交给大纲层，模型可以发挥 |

**核心判断：能结构化的全部结构化，只有"弧光"这种一句话的东西留给模型。**

## 2. 声纹：防 5000 章人物说话一个味

这是长篇最隐蔽的崩坏。读者不会说"人物 OOC 了"，他只会说"这本书不好看"。

每个角色必须有：

```python
voice = {
    "语气": "冷硬，少废话，情绪从不外露",
    "句长": "短",
    "口头禅": ["嗯", "走", "不用"],
    "禁用词": ["其实", "或许", "我觉得"],   # 这个角色绝不会说的话
    "自称": "我",
}
```

8 个角色的声纹**两两可区分**（校验会检查）：

| 角色 | 语气 | 口头禅 | 绝不说 |
|---|---|---|---|
| 林昭 | 冷硬，少废话 | 嗯 / 走 / 不用 | 其实 / 或许 / 我觉得 |
| 沈鹤年 | 慢，爱用反问 | 你说呢 / 未必 / 急什么 | 综上所述 / 必然 / 一定 |
| 苏见月 | 短促，带刺 | 废话 / 闭嘴 / 烦 | 抱歉 / 对不起 / 谢谢 |
| 陆无咎 | 阴阳怪气，敬语说狠话 | 有意思 / 请吧 / 恕不奉陪 | 谢谢 / 感激 |
| 白蘅 | 轻，几乎不表态 | …… / 也许吧 | 我保证 / 一定 / 肯定 |
| 天枢 | 无起伏，像念判词 | 依律 / 此非汝所能问 | 也许 / 或许 / 我想 |
| 林小满 | 直白，爱抱怨 | 哥 / 你别管 / 真的假的 | 在下 / 本座 / 道友 |
| 玄冥 | 平，慢，无感叹句 | 哦 / 继续 | 啊 / 呀 / 呢 |

**"禁用词"比"口头禅"更重要。** 口头禅让角色有辨识度，禁用词防止角色趋同——
如果所有人都能用"其实"，那所有人都变成了同一个声音。

## 3. 校验：三类问题

`validate()` 检查 3 类共 12 项。任何一条不过，`raise` 拒绝开写。

### A. 结构性（会让流水线崩）

| 检查 | 不通过的后果 |
|---|---|
| 境界序号在 1~108 内 | 索引越界 |
| 境界单调不减 | 人物倒退，设定崩塌 |
| 章号在 1~5000 内 | 里程碑永远触发不了 |
| 主角必须走到 108 阶 | 结局不到神主，故事不完整 |

### B. 叙事性（会让读者弃书）

| 检查 | 阈值 | 为什么 |
|---|---|---|
| 师父必须比主角强 | 高 ≥3 阶 | 否则教不了 |
| 但差距不能太大 | 高 ≤30 阶 | 否则主角像蝼蚁 |
| 反派登场必须比主角强 | >0 阶 | 否则冲突不成立 |
| 但差距不能太大 | ≤9 阶 | 否则读者觉得没法打 |
| 主角不能长期无敌 | 每 500 章内有人比他强 | 否则 5000 章没张力 |
| 死者不能复活 | 退场后无里程碑 | 世界规则 |

### C. 一致性（会让设定崩塌）

| 检查 | 为什么 |
|---|---|
| 名字/别名不重复 | 读者会混淆 |
| 声纹两两可区分 | 否则分不清谁在说话 |
| 每个角色都有声纹 | 否则 5000 章会漂移 |
| 关系双向 | 单向关系说明设定没想清 |

## 4. 踩过的坑

### 坑 1：主角过早无敌

第一次跑校验，直接报：

```
⚠️ 第 501~1000 章期间没有任何人比主角强，缺乏张力
⚠️ 第 2001~2500 章期间没有任何人比主角强，缺乏张力
⚠️ 第 2501~3000 章期间没有任何人比主角强，缺乏张力
⚠️ 第 3001~3500 章期间没有任何人比主角强，缺乏张力
⚠️ 第 3501~4000 章期间没有任何人比主角强，缺乏张力
```

原因：我给反派排的境界阶梯太弱。主角第 4000 章已经到第 79 阶（天道初期），
而我给陆无咎排的最终对决才第 104 阶——中间一大段没人跟得上。

**修法**：先查清主角在每个关键章的实际境界，再按它排反派。

```
主角第  900章 = 第 20 阶  → 陆无咎登场必须 >20
主角第 4201章 = 第 82 阶  → 天枢登场必须 >82，但 ≤91（差距≤9）
```

### 坑 2：人物从来没同步进正典

这是**最隐蔽的 bug**。`ContextBuilder` 里 `render_state()` 遍历 cast 时调
`canon.find(cid)`，但 `canon.entities` 是空的——因为人物从来没被写进正典。

结果：**「世界状态」块永远是空的**，模型完全不知道在场的人是谁、什么境界。

这个 bug 在空 canon 上跑**不会报错**，只是悄悄输出空块。

**修法**：加 `CH.sync_to_canon()`，把人物和不可变事实写进正典；
再加一条不变量 **INV-7** 专门检查「世界状态块非空」。

```
[INV-7] 注入的世界状态块非空
  ✅ 第    1章 世界状态块 318 字符，含实体=是，含境界=是
  ✅ 第 2400章 世界状态块 471 字符，含实体=是，含境界=是
```

### 坑 3：level_lookup 覆盖了显式事实

修完坑 2 后，INV-2 和 INV-5 反而失败了。原因：我让 `state_at()` 用人物轨迹
提供境界，但它**覆盖**了手工写的「境界」fact，导致测试数据被改。

**修法**：显式事实优先。

```python
if "境界" not in out and callable(self.level_lookup):
    out["境界"] = self.level_lookup(entity, chapter)
```

## 5. 主角排名：验证"没有过早无敌"

`power_ranking_at()` 输出主角在每个关键章的排名：

```
章号     排名   同场人数   当场最强
100     2/3    3        沈鹤年
1000    3/5    5        沈鹤年
2000    3/5    5        陆无咎
3000    1/4    4        林昭      ← 这一段无敌（灵界后期，无人能敌）
4000    1/4    4        林昭      ← 这一段也无敌
4500    2/4    4        陆无咎    ← 陆无咎追上来了
4999    1/4    4        林昭      ← 终局登顶
```

**3000~4000 章主角排第一是设计允许的**（灵界后期到仙界初期），
但 4500 章陆无咎追上来，制造了最后的张力。

> 如果 3000~4500 全程无敌，就该加一个新反派。这是可自动检测的。

## 6. 在大屏上看

打开大屏，**③·五 人物体系** 面板：

- 8 张人物卡，**当前章在场的角色会高亮**（青色边框）
- 每张卡显示：名字、角色、当前境界（第 N/108 阶）、语气、口头禅、绝不说
- 底部进度条 = 该角色当前境界占 108 阶的比例
- 已退场的角色变暗（如第 3000 章看苏见月）

拖动时间轴，人物卡会联动更新：

- 拖到 **第 1 章**：只有林昭、沈鹤年、林小满亮着
- 拖到 **第 2400 章**：8 个角色里 5 个在场，林昭与苏见月同为灵帝中期
- 拖到 **第 4500 章**：陆无咎排第一，林昭第二
- 拖到 **第 4999 章**：只剩林昭、沈鹤年、陆无咎、天枢
