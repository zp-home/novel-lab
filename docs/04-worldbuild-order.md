# 生成顺序：为什么世界观必须最先定

> 这是对 `03-longform-5000.md` 的补充。回答一个问题：

---

## 0. 先回答：顺序是错的（我原来的代码有漏洞）

你问的这个问题，暴露了我上一版实现里的一个**真实架构缺陷**。

看原来的执行顺序：

```
第 1 章开跑时：
  canon = Canon()           ← 空的！0 个实体、0 条规则
  → ensure_book_outline()   ← 模型凭空编世界观
  → ensure_volume_outline() ← 模型再编一套
  → 正文                     ← 模型再编一套
```

**没有任何一步建立世界观。** 后果是：第 1 卷模型发明境界叫"炼气→筑基→金丹"，
第 20 卷模型忘了，重新发明"凝气→聚元→化丹"。读者第 20 卷就会发现对不上，弃书。

这正是"AI 写长篇在第 100 章左右崩掉"的典型原因。**现在已经修好了。**

## 1. 正确的顺序（六步，不能调换）

```
┌─────────────────────────────────────────────────────────────┐
│ 第 0 步：世界观 + 力量体系        ← 硬编码，冻结，模型无权修改  │
│   四界 · 36 大境界 · 108 小阶 · 灵根 · 法宝 · 丹药 · 天劫      │
│   产物：world.json（只读）                                    │
└────────────────────────┬────────────────────────────────────┘
                         │ 依赖：无
┌────────────────────────▼────────────────────────────────────┐
│ 第 1 步：人物                   ← 半硬（依赖境界决定强弱）      │
│   主角/对手/师长/道侣，各自的境界、灵根、声音                   │
└────────────────────────┬────────────────────────────────────┘
                         │ 依赖：世界观
┌────────────────────────▼────────────────────────────────────┐
│ 第 2 步：全书总纲（脊柱）        ← 模型生成，但受世界观约束     │

└────────────────────────┬────────────────────────────────────┘
                         │ 依赖：人物 + 世界观
┌────────────────────────▼────────────────────────────────────┐
│ 第 3 步：卷纲（滚动，开写该卷才生成）                          │
│   每卷 50 章 · 明确"比上一卷强在哪"                            │
└────────────────────────┬────────────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────────────┐
│ 第 4 步：弧纲（滚动）→ 第 5 步：章纲（滚动）                    │
└────────────────────────┬────────────────────────────────────┘
                         │
┌────────────────────────▼────────────────────────────────────┐
│ 第 6 步：正文 → 回写正典 → 卷末审计                            │
└─────────────────────────────────────────────────────────────┘
```

### 为什么世界观必须最先，而且必须"硬"

**因为它是唯一不允许"随写随改"的东西。**

- 人物可以成长（炼气 → 筑基 → 金丹）
- 剧情可以调整（这一卷打谁）
- 但"境界有九层、不能跳级"这种规则，一旦定下，5000 章都不能变

如果让模型每次生成大纲时自己决定境界体系，它每次都会编一套新的。
**这不是模型不够聪明，是它没有记忆——它不知道第 20 卷时第 1 卷用过什么。**

所以世界观不是"设定文档"，是**编译期常量**：

```python
# 硬编码在代码里，不是模型生成的
REALMS = [
    {"name": "人界", "levels": ["炼气", "筑基", "金丹", ...]},
    {"name": "灵界", "levels": ["灵徒", "灵师", "灵王", ...]},
    ...
]
```

模型只能**引用**，不能**发明**。所有大纲 prompt 里都注入当前境界，
并明确写"世界观已定死，不可更改，不可自创境界名"。

## 2. 四界设定（`src/worldbuild.py`）

### 2.1 四界 × 九境 × 三阶 = 108 阶

| 界 | 章号 | 道法 | 九大境界 |
|---|---|---|---|
| **人界** | 1~1600 | 炼精化气 | 炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 |
| **灵界** | 1601~3000 | 炼气化神 | 灵徒 → 灵师 → 灵王 → 灵皇 → 灵尊 → 灵圣 → 灵帝 → 灵祖 → 灵源 |
| **仙界** | 3001~4200 | 炼神还虚 | 散仙 → 真仙 → 玄仙 → 金仙 → 太乙 → 大罗 → 混元 → 准圣 → 天道 |
| **神界** | 4201~5000 | 炼虚合道 | 神人 → 神使 → 神将 → 神君 → 神王 → 神皇 → 神帝 → 神尊 → 神主 |

每境三阶（初期/中期/后期），共 **4 × 9 × 3 = 108 阶**，
平均 **46.3 章/阶**，节奏合理。

### 2.2 节奏曲线：越往后越慢

境界不是均分章节的。后期境界耗时是前期的 2 倍多：

```
炼气初期      1~21章     21 章    ← 起步快，抓读者
金丹初期    168~205章    38 章
化神初期    441~496章    56 章    ← 进步明显变慢
渡劫初期  1313~1405章    93 章    ← 人界巅峰，占 93 章
神主后期  4953~5000章    48 章    ← 收尾加速
```

用权重 `1.0 + 0.145 * i` 实现。这是为了让读者**感知到进步变难**——
如果每阶都 46 章，读者会觉得"怎么升级这么容易"，爽感消失。

### 2.3 最关键的设计：解决战力膨胀

2000 万字，主角从凡人到神主。如果战力纯指数增长，到第 3000 章数字已经没有意义了。

**真实网文的解法是「换地图 + 界壁压制」，但这里有个陷阱我踩过：**

初版我把界壁压制实现成"飞升后战力下降"：

```python
人界渡劫后期  power = 1e6
灵界灵徒初期  power = 1e3      ← 降了 1000 倍
```

结果校验器同时报两个错：

```
❌ 战力倒退：渡劫后期(1e6) → 灵徒初期(1e3)
❌ 界壁压制失效：...
```

**两条规则互相打架。** 这说明我的模型是错的。

正确的仙侠逻辑是：

> **绝对战力只涨不跌，但相对排名会重置。**

渡劫大能飞升灵界，绝对战力仍高于人界任何人，
但**在灵界只是最底层灵徒**——这就是"界壁压制"的真实含义。

所以用两个字段：

```python
Level(power=1e6,  rank=1.0)   # 人界渡劫后期：绝对战力 1e6，界内地位 100%
Level(power=2e6,  rank=0.0)   # 灵界灵徒初期：绝对战力 2e6（涨了），界内地位 0%（重置）
```

- `power`：全书单调递增，用于跨界的绝对比较
- `rank`：每界 0→1 重新走一遍，用于"这人在这界算强还是弱"

**这是整个世界观设计里最重要的一处。** 它同时满足了：
- 飞升是变强（符合读者直觉）
- 换地图后重新开始（避免数字爆炸）
- 战力曲线可校验（`validate()` 能自动检查）

## 3. 其他元素

```python
SPIRIT_ROOTS   = 单灵根 / 双灵根 / 三灵根 / 四灵根 / 五灵根 / 变异灵根 / 伪灵根

PILL_TIERS     = 一品 ~ 九品
TRIBULATIONS   = 人界·渡劫 / 灵界·灵源 / 仙界·天道 / 神界·神主
```

世界硬规则（7 条，注入每章 prompt）：

1. 境界共四界三十六境，每境三阶，共一百零八阶
2. **境界不可跳级**。可借外力短时爆发，但事后必然反噬
3. **跨界飞升受界壁压制**，境界暂时跌落至新界底层
4. **死者不可复生**。任何复活情节都是设定错误
5. **神格唯一**。同一神格不能同时存在两个持有者
6. 灵气浓度：人界 1，灵界 100，仙界 10000，神界 1000000
7. 凡人无法感知灵气。踏入炼气期是唯一分界线

## 4. 校验：世界观不通过就不许开写

`validate()` 检查 6 项，任何一项不过就 `raise`，拒绝启动流水线：

| 检查 | 为什么重要 |
|---|---|
| 章号无缝覆盖 1~5000 | 有空洞 → 流水线在第 N 章卡死 |
| 每阶至少 1 章 | 0 章 → 那一阶永远写不到 |
| 单阶不超上限 | 占 400 章 → 读者觉得卡关 |
| 绝对战力单调递增 | 倒退 → 设定自相矛盾 |
| 界内 rank 每界重置 | 不重置 → 界壁压制失效，数字爆炸 |
| 阶数 ≥ 50 | 太少 → 撑不住 5000 章 |

**这比"设定写得好不好"重要得多。** 设定可以改，但结构性错误会让整个流水线崩掉。

实测输出：

```
✅ 世界观可运行：章号无缝、战力单调、界壁压制有效、节奏合理
```

## 5. 注入 prompt 的样子（大小恒定）

第 1 章、第 2000 章、第 4999 章注入的力量体系块**都是 250 字符左右**：

```
【力量体系 · 第 2000 章】
当前界：灵界（炼气化神。灵界以灵根为本，无灵根者如凡人。）
当前境界：灵尊初期（第 1989~2037 章）
下一阶：灵尊中期（第 2038 章起）
本界境界序列：灵徒 → 灵师 → 灵王 → 灵皇 → 灵尊 → 灵圣 → 灵帝 → 灵祖 → 灵源
硬规则：境界共四界三十六境…；境界不可跳级…；跨界飞升受界壁压制…；死者不可复生…
```

**只渲染"当前界 + 当前境界 + 下一阶"，不把 108 阶全列出来。**
这是上下文恒定的又一保证。

## 8. 一句话总结

**顺序是：世界观 → 人物 → 总纲 → 卷纲 → 弧纲 → 章纲 → 正文。**

世界观必须**最先、且硬编码**，因为它是唯一不能随写随改的东西。
它是 5000 章的地基——地基错了，后面 2000 万字全是废的。
